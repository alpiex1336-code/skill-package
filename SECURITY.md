# Security Policy

This repository contains markdown guidance for agent workflows. It should not contain credentials, private endpoints, recovery codes, customer data, or proprietary internal policy.

## Reporting

If you find a security issue in this repository, such as accidentally committed secrets or guidance that would cause unsafe tool use, report it through GitHub's private vulnerability reporting if enabled, or open a minimal issue that avoids exposing sensitive details.

## Supported versions

The default branch is the supported version unless release tags are added later.
